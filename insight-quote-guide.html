엔도톡신 시약 견적을 받기 전에 준비할 것

엔도톡신 시약(LAL·rFC·rCR·Gel-clot)의 견적은 시험 방식·감도(λ)·용량·월 사용량에 따라 단가와 리드타임이 크게 달라집니다. 담당자에게 아래 4가지를 전달하면 첫 회신에서 정확한 견적이 나옵니다.

  1. 시험 방식 — Gel-clot / Kinetic Turbidimetric / Kinetic Chromogenic / End-point Chromogenic / rFC / rCR / MAT
  2. 감도(λ) — 0.001 / 0.005 / 0.03 / 0.06 / 0.125 / 0.25 / 0.5 EU/mL
  3. 용량 단위 — vial 수 · pack 수 · tests/box (예: KC0828 = 208 tests/box)
  4. 월 예상 사용량 · 정기 여부 — 정기 계약 시 딜러가 적용 가능

  • 기관명·QC 팀명·담당자·연락처

CoA · MSDS · package insert 원본 요청

배송 전에 CoA(Lot 별 성능시험 성적서)와 package insert 원본을 이메일로 먼저 회신해 드립니다.

배송·보관·리드타임

  • 국내 재고 상시 품목 (KC·KT·EC·Gel-clot 대부분): 발주 확정 후 3~7영업일
  • 재조합 시약(rFC·rCR): 국내 재고 시 3~7일, 재고 부족 시 본사 수입 2~4주
  • 배송: 2~8°C 콜드체인 (CJ대한통운·특송)
  • 수령 즉시 −20°C 냉동 보관 원칙
